# TimeLimiter (`main.py`)

Автономная программа родительского контроля экранного времени для ПК под управлением Windows 10/11.

---

## 1. Описание и назначение

Программа предназначена для установки жесткого суточного лимита использования компьютера (по умолчанию — **60 минут в день**). Скрипт предотвращает обход ограничений ребенком путем перезагрузки или повторного включения ПК.

### Основные возможности:

* **Суммарный суточный учет:** Каждую минуту работы ПК время суммируется. Если ноутбук выключали или перезагружали, отсчет продолжается с сохраненной минуты.
* **Принудительное выключение:** При достижении лимита мгновенно вызывается завершение работы Windows (`shutdown /s /f /t 0`).
* **Защита от повторного входа:** При включении ПК с исчерпанным лимитом выводится окно запроса родительского пароля с 5-минутным таймером. Если пароль не введен за 5 минут, ноутбук выключается снова.
* **Автоматический сброс:** При наступлении следующего календарного дня (смене даты) счетчик обнуляется автоматически.
* **Скрытый режим:** Работает в фоне без отображения консольных окон.

---

## 2. Логика работы приложения

1. При запуске система считывает файл состояния `C:\ProgramData\timer_data.txt`.
2. Если текущая дата совпадает с сохраненной, отсчет продолжается с предыдущего значения.
3. Каждые 60 секунд значение счетчика увеличивается на 1 и перезаписывается на диск.
4. При превышении `LIMIT_MINUTES` запускается процедура выключения системы или запроса пароля.

---

## 3. Требования к системе

* **Операционная система:** Windows 10 / Windows 11.
* **Среда разработки:** Python 3.12+ (необходим только на этапе сборки `.exe`).
* **Зависимости:** `PyInstaller` (указывается в `requirements.txt`).
* **Права доступа:** Права Администратора для размещения файла в системном автозапуске.

---

## 4. Пошаговая инструкция по сборке `.exe`

### Шаг 1. Подготовка зависимостей

Убедитесь, что в рабочей директории проекта созданы файлы `timer.py` и `requirements.txt`. Выполните в терминале команду установки:

```powershell
pip install -r requirements.txt
```

### Шаг 2. Компиляция исполнения

Скомпилируйте скрипт Python в один автономный бинарный файл без консольного окна:

```powershell
pyinstaller --noconsole --onefile main.py
```

После завершения процесса скомпилированный файл `main.exe` будет находиться в папке `dist\`.

---

## 5. Установка в системный автозапуск

Чтобы программа запускалась автоматически для любой учетной записи при старте Windows, выполните команду копирования `.exe` файла в системную директорию `StartUp`:

```powershell
copy-item "dist\timer.exe" "C:\ProgramData\Microsoft\Windows\Start Menu\Programs\StartUp\timer.exe" -Force
```

---

## 6. Настройки в коде (`timer.py`)

Вы можете настроить ключевые параметры программы перед сборкой в блоке `# --- НАСТРОЙКИ ---`:

* `LIMIT_MINUTES = 60` — дневной лимит времени за ПК (в минутах).
* `GRACE_MINUTES = 5` — время ожидания ввода пароля при повторном включении (в минутах).
* `PASSWORD = "1234"` — родительский пароль для разблокировки и продления сессии.
